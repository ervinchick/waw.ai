# WAW — умный собеседник, который всегда под рукой

**Попробовать:** https://ervinchick.github.io/waw.ai/

WAW — разговорный ИИ от Wawid Studios. Пиши, спрашивай, спорь, придумывай, присылай фото и документы. Всё в одном окне, которое открывается в любом браузере и на телефоне, без установки.

## Почему WAW

- **Без установки.** Открыл ссылку и начал разговор. Работает на компьютере, планшете и телефоне.
- **Твои диалоги в облаке.** Войди один раз, и история будет на каждом устройстве.
- **Выбор модели.** Быстрая для коротких вопросов, универсальная для повседневных задач или продвинутая для глубоких разборов. Переключается в один тап.
- **Честные ответы.** WAW говорит прямо, не подлизывается и не читает нотации. Обсуждает сложные темы без ухода в сторону.

## Что умеет

**Разговор**
- Ответы появляются по мере написания, как в живом чате. Можно отключить в настройках.
- Режим «Рассуждения» показывает короткое обоснование перед ответом.
- Режим «Roleplay» делает разговор живее и образнее.
- Можно остановить ответ, продолжить его или переписать другой версией. Все версии сохраняются.
- Своё сообщение можно отредактировать, и ответ сгенерируется заново.

**Файлы и фото**
- Прикрепляй картинки, PDF, текстовые файлы и код. WAW ответит по их содержанию.
- Сделай фото прямо с телефона.
- Перед отправкой можно нарисовать поверх фото, добавить текст или обрезать его.

**Порядок в диалогах**
- Поиск по названиям и содержимому диалогов.
- Закрепление важных диалогов наверху.
- Экспорт любого диалога в Markdown одной кнопкой.
- Быстрые шаблоны: перескажи, переведи, исправь ошибки, объясни проще, сделай короче.
- Счётчик символов и примерного числа токенов.

**Под себя**
- Персональная инструкция: как WAW должен с тобой общаться.
- Имя, которым к тебе обращаются.
- Светлая, тёмная или системная тема и 6 акцентных цветов.
- Статистика по твоим диалогам.

## Как начать

1. Открой https://ervinchick.github.io/waw.ai/
2. Зарегистрируйся по email или войди через Google.
3. Напиши первое сообщение. Всё, остальное понятно по ходу.

Если у тебя уже была история диалогов на этом устройстве, её можно перенести в аккаунт в один клик. Оригиналы останутся на месте.

## Для разработчиков

Сайт — обычный статический фронтенд (HTML, CSS, JavaScript) без сборки. Данные аккаунтов и история хранятся в облаке, запросы к модели идут через защищённый сервер, ключи API на сайт не попадают.

Исходники открыты, так что можно посмотреть, как всё устроено, или развернуть свою копию на GitHub Pages.
