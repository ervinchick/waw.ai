# WAW — веб-интерфейс

Полноценный веб-чат в духе «настоящей нейросети» для бота WAW (Wawid Studios):
боковая панель с чатами, нижняя панель ввода с переключателями «Рассуждения» и
«Roleplay», выезжающие настройки с персонализацией, фиолетовая акцентная тема.

Чистый HTML/CSS/JS без сборки — можно сразу открыть `index.html` или
задеплоить на GitHub Pages.

## Возможности

- **Сайдбар с чатами**: создание, переключение, удаление, автоназвание чата по первому сообщению
- **Нижняя панель ввода**: авто-рост textarea, отправка по Enter (Shift+Enter — перенос строки), переключатели «Рассуждения» / «Roleplay»
- **Рассуждения**: если включены, ответ может сопровождаться коротким блоком-обоснованием над текстом (аналог `THINK_SUMMARY` из бота)
- **Настройки** (боковая панель справа):
  - Персонализация: имя пользователя, персональная инструкция (как в `/personal` у бота)
  - Внешний вид: акцентный цвет (4 варианта), светлая/тёмная тема
  - Поведение по умолчанию: рассуждения и roleplay
  - Адрес API-сервера
  - Полный сброс данных
- Всё состояние хранится в `localStorage` браузера — работает без бэкенда «из коробки»

## Запуск

Просто открой `index.html` в браузере, либо через GitHub Pages:

1. Запушь эту папку в репозиторий на GitHub
2. Settings → Pages → Source: `main` / `/ (root)`
3. Готово, сайт появится на `https://<username>.github.io/<repo>/`

## Подключение к своему API-серверу

По умолчанию сайт работает в демо-режиме прямо в браузере (без сервера).
Чтобы подключить настоящего бота:

1. В настройках сайта укажи адрес: **Настройки → Подключение → Адрес API-сервера**
2. На этот адрес сайт будет слать `POST`-запрос вида:

```json
{
  "messages": [{ "role": "user", "text": "привет" }],
  "personalInstruction": "отвечай кратко",
  "reasoning": true,
  "roleplay": false
}
```

3. Сервер должен ответить:

```json
{
  "text": "текст ответа",
  "reasoning": "необязательное краткое обоснование"
}
```

Со стороны Node/Express такой эндпоинт можно собрать поверх уже существующей
логики из `bot.ts` — переиспользуй `askWithProviderFallback(...)` и
`buildSystemInstruction(...)`, просто вызывая их из HTTP-хендлера вместо
Telegram-хендлера, и данные из `store.ts` (историю чата, персональную
инструкцию) — через тот же `userId`.

Из соображений безопасности CORS и API-ключи настраивай на сервере, а не в
браузере: ключи Gemini/OpenAI никогда не должны попадать в этот фронтенд.

## Структура

```
waw-web/
├── index.html    — разметка
├── styles.css    — вся тема (токены цвета в :root)
├── script.js     — состояние, рендер, отправка сообщений
└── README.md
```

## Кастомизация

- Акцентные цвета заданы как `[data-accent="..."]` в `styles.css` — легко добавить свой
- Шрифты: Sora (интерфейс) + Inter (текст сообщений), подключены через Google Fonts
- Логика ответа — функция `getReply()` в `script.js`
